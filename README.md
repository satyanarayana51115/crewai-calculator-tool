# CrewAI Custom Calculator Tool Integration

An agentic AI implementation using **CrewAI** that demonstrates custom Python tool integration. The agent performs mathematical calculations and data analysis using specialized tool execution.

## 📌 Features
- Custom Python function wrappers integrated as CrewAI tools.
- Precise multi-step calculation handling by AI agents.
- Clean separation of agent roles, tasks, and available tools.

## 🛠️ Tech Stack
- Python 3.10+
- CrewAI Framework
- OpenAI / LangChain Integrations
